# Definition of Done

Een story is pas Done nadat de implementatie via een pull request in `main` is gemerged én alle onderstaande afspraken gelden. Vul als team de eigen aanvullingen aan tijdens de start van het project.

## Standaard

- Alle acceptatiecriteria van de gekoppelde story zijn behaald.
- Het testplan is uitgevoerd; het resultaat en eventueel bewijs staan in de pull request.
- De oplossing is leesbaar, onderhoudbaar en voldoet aan de teamafspraken voor codekwaliteit.
- Relevante documentatie, diagrammen en configuratie zijn bijgewerkt.
- Alle vereiste GitHub Actions-checks slagen.
- De pull request verwijst met `Closes #nummer` naar precies één story.
- Minimaal één ander teamlid heeft de pull request gereviewd en goedgekeurd.
- Reviewgesprekken zijn opgelost voordat de pull request wordt gemerged.
- De branch is in `main` gemerged; de story is daarna gesloten en krijgt status Done.
